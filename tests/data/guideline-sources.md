# Sources of the architecture guidelines

Test data of `tests/guidelines.test.mjs`: every statement of an architecture guideline in the `dotnet-shared`, `blazor-server` and `blazor-wasm` packs carries one of the source keys below. The guidelines were drawn from the solution templates and reference solutions of the upstream harness packs; the keys stay so that each statement keeps a traceable source.

Source keys used in the architecture tables: CI-S, APP, BFF, PRES, DOM, PERS, NSB, CL-S, CI-W, CFE, REFIT-W, LOG, CL-W, code, as defined at the head of each table.
